## ⚡ Tech Stack & Features

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS (Deep Dark Mode `#09090b` + Adaptive Light Mode)
- **Animations:** Framer Motion (Smooth entrance animations, interactive hover dynamics)
- **Icons:** Lucide Icons & Custom SVG Icon components
- **Infinite Marquee:** Hardware-accelerated infinite slider for core technologies (Next.js, React, AI Agents, Interactive Dashboards, SaaS, Shopify/WordPress, TypeScript, Tailwind, Supabase) with pause-on-hover
- **Bento Grid Showcase:** Filterable project showcase across AI Web Apps, Dashboards, E-Commerce / SaaS, and WordPress
- **Dedicated Admin Route:** Password-protected `/admin` management hub for real-time CRUD operations
- **SEO & Performance:** 100% Lighthouse-optimized, OpenGraph cards, structured schema metadata

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ (tested on Node 24)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Bandebuche/portfolio-.git

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
